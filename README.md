# 네뷸라이저

같은 방의 방향 네뷸라이저를 폰으로 맞추는 앱입니다. 향을 고르는 계산은 기기 PCB에 있고, 폰은 앞에 켜 둔 설정 도구입니다. 계정, 클라우드, Wi-Fi, Matter는 없습니다. 치료 기기나 가습기가 아닙니다.

`01`, `start01`, `start02`는 예전의 Git 연습 파일입니다.

## 시장에 이미 있는 것

2026년 공개 안내 기준입니다. 아래는 새 기능이 아니라, 그 앱들이 이미 하는 일의 범위입니다.

- Pura: 강도, 향 전환, 타이머, 요일 스케줄. 바이알을 알아보고 잔량을 보여 줍니다. 집 밖 조작은 Pura Cloud이고, Away Mode는 폰 위치입니다. 계정이 있습니다.
- Aera: Wi-Fi와 계정. 켜기/끄기, 강도(본체 1–10, 미니 5), 디퓨저당 스케줄 약 20개. 자정을 넘는 예약은 둘로 나눕니다. 향 잔량과 다시 주문 알림이 있습니다.
- Moodo: 캡슐 강도, 프리셋, 스케줄에 향을 묶기, 인터벌(켜짐/꺼짐), 캡슐 잔량. 계정으로 기기를 나눕니다.

이 앱이 그 기본에서 v1 연결에 맞춘 것:

- 기기 버튼으로 여는 짧은 페어링
- 켜기/끄기
- 1–5단. 단은 전압이 아니라 버스트 간격
- 주간 예약 전체 교체. 실행은 기기 시계
- 향 이름과 잔량 추정
- 이름의 장면. 장면은 버스트 단수
- 동작, 단수, 고장, 장착, 시각, 펌웨어
- 한 번 분사
- 조용한 시간

위치 기반 외출 모드, 가족 계정, 집 밖 조작은 일부러 없습니다.

## PCB에서만 하는 차이

- 자동 / 고정. 자동이면 기기가 단수와 버스트 창을 제안합니다. 고정이면 폰에서 고정한 단수가 이깁니다.
- 결정 카드. 기기가 이유 코드(시각, 최근 분사, 카트리지, 메시 냉각)를 보내고, 폰이 짧은 한국어로 바꿉니다. 클라우드 모델은 없습니다.
- 받아들이기, 30분 미루기, 이 단수로 고정.
- 기기 안의 짧은 기록. 붙었을 때 읽습니다.
- 메시 보호(연속 켜짐 상한, 휴식). 화면에 보이고, 앱은 우회하지 못합니다.
- 로컬 전용 표시. 가입이 없습니다.

## 실행

```bash
cd nebulizer
npm install
npm test
npm run web
```

웹은 브라우저에서 검토용입니다. 폰은 같은 폴더에서 `npx expo start`로 Expo Go에 붙입니다. iOS 시뮬레이터 빌드는 Mac이 필요하고, Android는 에뮬레이터나 Expo Go를 씁니다. 백그라운드에서 깨워 분사하지 않습니다.

실제 GATT로 바꿀 때는 `src/transport.ts`의 `GattTransport`만 교체합니다. `EXPO_PUBLIC_LINK=gatt`이면 라디오 모듈이 없다는 오류만 납니다. 이 저장소 빌드는 시뮬레이터 링크가 기본입니다.

## 시뮬레이터의 한계

- 전파가 없고, GATT 소켓도 없습니다. 화면의 기기 그림은 개발·검토용입니다.
- 본딩, 예약, 향 이름, 결정 기록은 페이지 메모리입니다. 새로고침하면 사라집니다. 실제 기기는 플래시와 RTC에 남습니다.
- 잔량 퍼센트는 누적 분사 초로 나눈 추정입니다. 수위 센서가 아닙니다.
- 메시 온도나 전류를 재지 않습니다. 연속 켜짐 상한과 휴식만 펌웨어 규칙으로 흉내 냅니다.
- OTA 특성 UUID만 예약되어 있고, 전송은 없습니다.
