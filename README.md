# Shopping_Project
자바 스프링부트 펫 쇼핑몰


👥 팀원별 역할 분담

본 프로젝트는 총 4명의 팀원으로 구성되어 있으며, 각 담당 기능에 따라 프론트엔드와 백엔드 개발을 분담하여 진행합니다.

1. 회원 담당 (Member)

담당 기능: 회원가입 · 로그인 · 마이페이지

Frontend

회원가입 페이지 구현
로그인 페이지 구현
마이페이지 구현
회원정보 수정 페이지 구현

Backend

Member Entity 구현
회원가입 및 로그인 처리
비밀번호 암호화
세션 로그인 및 로그아웃 기능 구현
회원정보 조회 및 수정 기능 구현
2. 상품 담당 (Product)

담당 기능: 상품 · 카테고리 · 검색

Frontend

상품 목록 페이지 구현
상품 상세 페이지 구현
카테고리별 상품 페이지 구현
상품 검색 화면 구현

Backend

Product, Category Entity 구현
상품 목록 조회 기능 구현
카테고리별 상품 조회 기능 구현
상품 상세 조회 기능 구현
상품 검색 기능 구현
관리자 상품 등록 / 수정 / 삭제 기능 구현
3. 장바구니 담당 (Cart & Wishlist)

담당 기능: 장바구니 · 찜하기

Frontend

장바구니 페이지 구현
장바구니 상품 수량 변경 기능 구현

장바구니 담기 기능 구현

장바구니 총금액 계산 기능 구현
찜하기 및 찜 취소 기능 구현
